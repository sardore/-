# 스윙바이 SWINGBY — 기획서

**한 줄 요약**: 터치 한 번으로 궤도를 벗어나 다음 행성의 중력에 낚이는, 원터치 궤도 로그라이트. 10행성마다 항성 보스가 나타나 몸통 박치기로 쓰러뜨린다. 최종 보스는 TON 618.

## 핵심 루프
1. 우주선은 행성 주위를 자동으로 공전한다.
2. **터치** → 그 순간의 접선 방향(점선)으로 직진한다.
3. 다른 행성의 포획 범위(점선 원)를 **스쳐 지나가면** 가장 가까워진 지점에서 궤도에 붙는다.
4. 7개 행성마다 섹터 돌파 → 강화 3장 중 1장 선택.

## 긴장을 만드는 규칙
| 규칙 | 의도 |
|---|---|
| 궤도는 계속 좁아진다 (붕괴 → 추락) | 한 행성에 눌러앉지 못하게 하는 시간 압박 |
| 한 바퀴 돌기 전에 떠나면 콤보 +1 | 빠른 판단에 보상, 망설이면 콤보 초기화 |
| 가까이 스칠수록 궤도가 작고 빠르다 (+근접 스윙 보너스) | 위험할수록 점수가 큰 리스크/리턴 |
| 정면으로 들이받으면 충돌 | 조준에 의미 부여 |
| 자유 비행은 산소 제한 | 빗나간 발사의 대가 |
| 좌우 벽은 튕긴다 | 뱅크샷이라는 고급 루트 |

## 천체
- **일반 행성** — 기준.
- **적색왜성** (작고 붉게 맥동) — 포획 범위가 좁고 붕괴가 2.2배 빠름. 점수 2배.
- **가스 거인** (고리) — 포획 범위가 넓고 붕괴가 절반. 숨 돌리는 곳.
- **블랙홀** — 닿으면 즉사. 8번째 행성 이후 등장.
- **별** — 행성 사이 항로에 배치. +5점.

## 강화 (섹터마다 3택 1)
중력 증폭(포획 범위) · 안정 궤도(붕괴 감속) · 산소 탱크(비행 시간·보스전 산소) · 별 자석(수집 범위) · 비상 추진기(1회 부활) · 항해 일지(점수 배율) · 박치기 강화(보스 피해)

## 보스전 (대규모 업데이트)
10개 행성을 넘으면(보스를 잡은 뒤엔 다시 10개) 항성 보스가 나타난다. 이때 현재 행성을 중심으로 **아레나**가 열리고 카메라가 고정된다.
행성은 4~6개이고, 모든 행성에서 보스까지 직선 경로가 다른 행성의 포획 범위에 막히지 않도록 배치를 검증한다.

### 규칙
- **산소 게이지가 크게 늘어난다** (22초 + 보스 번호×5초, 산소 탱크 +3초). 날아다닐 때만 줄고, **궤도에 붙어도 회복되지 않는다.** 0이 되면 사망.
- **공격 수단은 박치기뿐.** 자유 비행 중 보스 몸통에 닿으면 피해(기본 26, 연속 박치기 콤보 최대 +72%, 박치기 강화 +25%/Lv). 맞으면 튕겨 나가 계속 날아간다.
- **보스는 우주선이 행성에 착지할 때마다 1턴.** 공격은 항상 예고(카운트다운 칩 + 월드 표시)되고, 0이 되는 턴에 발동한다.
- 보스에게 맞으면(운석·혜성·광선·폭발) 산소 -3.5초, 콤보 초기화, 넉백. 아레나 바닥에 부딪혀도 산소 -0.8초.
- 보스전 중 궤도 붕괴는 40% 속도로 느려져 조준할 시간을 준다.
- 체력 50%(TON 618은 66%/33%)에서 **분노 페이즈** — 예고 슬롯이 하나 늘어난다.
- 비상 추진기는 보스전에서도 유효 (부활 시 산소 최소 6초 보충).

### 공격 패턴 (모두 예고됨)
| 패턴 | 설명 |
|---|---|
| 운석 | 예고 세로선을 따라 2~4개 낙하 |
| 혜성 | 가로로 가로지르는 빠른 탄 |
| 광선 | 보스에서 지정 각도로 레이저, 얇게 예고 후 발사 |
| 제트 | (TON 618) 양쪽 사선으로 두꺼운 광선 |
| 플레어 | 보스 중심 확산 링 — 궤도 위에서도 맞는다 |
| 블랙홀 | 아레나에 블랙홀 생성, 자유 비행 중 끌어당기고 몇 턴간 유지 |
| 행성 붕괴 | 행성 하나가 폭발하며 사라짐 → 4턴 뒤 다시 생성. 올라타 있던 행성이면 터지기 전에 떠나야 한다 |
| 항성풍 | 한 턴 동안 좌우로 우주선을 미는 바람 |

## 타격감
히트스톱 · 슬로모션 · 줌 펀치 · 화면 플래시 · 화면 흔들림 · 확산 링/방향성 스파크 · 레이어드 합성음(타격 저음 + 노이즈 + 톤) · 진동(`navigator.vibrate`) · 행성 찌그러짐/맥동 · 별 수집 음정 체인 · 배너/토스트 연출 · 보스 사망 연출(연쇄 폭발 + 슬로모션).

## 테스트 훅
`window.__dbg` — `get/jump(i)/sim(sec,{nobot})/set({hp,o2,shield,hops})`. 로직(`step`)과 렌더(`draw`)가 분리되어 있어 헤드리스로 보스전을 시뮬레이션할 수 있다.

## 난이도 곡선
행성을 넘을수록 비행 속도↑, 붕괴 속도↑, 포획 범위↓, 행성 간격↑, 블랙홀 빈도↑.

## 조작
터치 / 클릭 / 스페이스. 강화 선택은 터치 또는 1·2·3.

## 구현
`index.html` 단일 파일, Canvas 2D + WebAudio, 외부 의존성 없음. 최고 기록은 localStorage.
