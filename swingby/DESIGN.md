# 스윙바이 SWINGBY — 기획서

**한 줄 요약**: 터치 한 번으로 궤도를 벗어나 다음 행성의 중력에 낚이는, 원터치 궤도 로그라이트. 항성 보스를 몸통 충돌로 쓰러뜨리고, 보스 사이의 **갈림길**에서 항로(다음 보스·행성 스타일)를 고른다. 최종 보스는 TON 618.

## 핵심 루프
1. 우주선은 행성 주위를 자동으로 공전한다.
2. **터치** → 그 순간의 접선 방향(점선)으로 직진한다.
3. 다른 행성의 포획 범위(점선 원)를 **스쳐 지나가면** 가장 가까워진 지점에서 궤도에 붙는다.
4. 8번째 행성에서 기체가 2단으로 진화하고, 보스를 잡을 때마다 더 큰 기체로 진화한다 (아래 '기체 진화'). 일부 상위 기체는 **길게 눌렀다 떼면 돌격**한다.

## 긴장을 만드는 규칙
| 규칙 | 의도 |
|---|---|
| 궤도는 계속 좁아진다 (붕괴 → 추락) | 한 행성에 눌러앉지 못하게 하는 시간 압박 |
| 한 바퀴 돌기 전에 떠나면 콤보 +1 | 빠른 판단에 보상, 망설이면 콤보 초기화 |
| 가까이 스칠수록 궤도가 작고 빠르다 (+근접 스윙 보너스) | 위험할수록 점수가 큰 리스크/리턴 |
| 정면으로 들이받으면 충돌 | 조준에 의미 부여 |
| 자유 비행은 산소 제한 | 빗나간 발사의 대가 |
| 좌우 벽은 튕긴다 | 뱅크샷이라는 고급 루트 |

## 천체
- **일반 행성** — 기준.
- **적색왜성** (작고 붉게 맥동) — 포획 범위가 좁고 붕괴가 1.8배 빠름. 점수 2배.
- **가스 거인** (고리) — 포획 범위가 넓고 붕괴가 절반. 숨 돌리는 곳.
- **소행성** (갈라진 바위, 적색왜성보다 크다) — 포획 범위가 좁고 붕괴가 1.15배 빠름. **떠나는 순간 부서져 다시 앉을 수 없다.** 소행성대에서만 나온다.
- **거대 암석 행성** (크레이터) — 갈림길의 허브. 포획 범위가 매우 넓고 궤도 붕괴가 거의 없다(0.08배).
- **블랙홀** — 닿으면 즉사. 8번째 행성 이후 등장.
- **별** — 행성 사이 항로에 배치. +5점.

## 능력치 — 퍼센트, 100% = Lv1 기본 기체
능력치는 "+1" 같은 단계가 아니라 **퍼센트**로 표시한다. 기본 기체(스카우트)가 전부 100%이고, 추진기만 개수다.

| 능력치 | 게임에서의 의미 |
|---|---|
| 속도 | 비행 속도 × (궤도 회전 속도는 바뀌지 않는다) |
| 충돌 | 보스 충돌 피해 × |
| 인력 | 행성 포획 링의 폭 × · 별 수집 범위 × (포획과 자석을 하나로 통합) |

- **인력은 수확 체감**: 포획 링은 150%까지는 비례하고 그 위로는 효과가 40%만 붙는다(300% → 약 210%). 너무 넓으면 원하는 행성을 고를 수 없고 큰 궤도는 회전이 느려 답답해지기 때문. 또 궤도 반지름은 기본 링의 1.45배까지만 허용하고, 더 먼 궤도로 붙으면 부드럽게 끌려 들어온다. 별 수집 범위는 그대로 비례한다. (`stats.js` `ringMul`·`maxOrbit`)
| 궤도 | 궤도 붕괴 속도 ÷ (높을수록 오래 버틴다) |
| 산소 | 비행 가능 시간 × · 보스전 산소 풀에 절반 반영 |
| 점수 | 모든 점수 × |
| 추진기 | 사망 1회 방지 (개수) |

변환 규칙은 `js/stats.js` 한 파일에 모여 있다. 기체의 증가량은 `js/ships.js` 에서 **퍼센트포인트**로 정의한다(예: 요격기 `{spd:8, ram:25, shield:1}`).

**능력치 다각형(레이더)**: 속도·충돌·인력·궤도·산소·점수 6축. 점선 고리가 100%, 바깥 고리가 240%. 진화 화면에서는 선택지마다 **현재 기체(흰 점선)와 진화 후(색 면)** 를 겹쳐 그리고, 바뀌는 능력치는 `충돌 125%` 같은 칩으로 새 값을 보여 준다. 강화 카드는 `220% → 232%` 와 함께 변화한 다각형 미리보기를 보여 준다.

## 기체 진화 (테크트리) — 능력치는 기체를 따라온다
업그레이드 카드는 더 이상 초반부터 뿌리지 않는다. 대신 **기체가 최대 4단까지 진화**하고, 능력치는 고른 기체가 가진다. 단이 오를수록 외형이 더 복잡하고 커진다 (1.0× → 1.35× → 1.75× → 2.2×).

| 시점 | 진화 | 선택지 |
|---|---|---|
| 8번째 행성 (첫 보스 직전) | 1단 → **2단** | 요격기 / 순양함 / 탐사선 — **모든 루트가 비상 추진기 +1을 가진다** |
| 2번째 보스 격파 후 | 2단 → **3단** | 각 루트당 2갈래 (총 6종) |
| 5번째 보스 격파 후 | 3단 → **4단** (보스가 8종으로 늘어 후반 진화를 늦췄다. `EVOLVE_AT`) | 각 기체당 2갈래 (총 12종) |
| 4단 이후 | 기존 **강화 카드**가 4행성마다(자주) + 보스 격파 시 등장 | 아래 풀 |

- **요격기 계열**(충돌·속도): 파쇄함 → 드레드노트 / 저거너트, 질풍함 → 팬텀 / 템페스트
- **순양함 계열**(궤도 안정·산소·비상 추진기): 방벽함 → 요새함 / 이지스, 보급함 → 방주 / 대양선
- **탐사선 계열**(포획 범위·별·점수): 항해선 → 성도선 / 웜홀선, 수확선 → 은하 수확선 / 황금 상선
- **형제 기체는 서로 우열이 없게 짠다**: 능력치를 강화 카드 한 장 분량(속도 5·충돌 12·인력 10·궤도 12·산소 12·점수 10)으로 환산해 합산하고(점수는 절반, 추진기 1개 = 카드 4장), 같은 부모의 두 갈래가 비슷한 값이 되도록 맞춘다. 돌격 기체는 돌격 덕에 합이 조금 낮다. 한쪽이 모든 항목에서 앞서는 쌍이 없어야 한다(항해선은 추진기 +1을 가져 수확선과 갈린다).
- 기체는 `drawShip()` 으로 절차 생성한다 (몸체 3종 × 날개·포드·패널·접시안테나·포·가시·링·드론 조합). 기체 크기에 따라 피격/충돌 판정도 조금씩 커진다.

### 차지 돌격 (일부 상위 기체)
파쇄함·질풍함·드레드노트·저거너트·팬텀·템페스트·웜홀선은 **누르고 있으면 차지, 떼면 돌격**한다. 일반 기체는 누르는 순간 발사.
- 차지는 0.8초에 가득 찬다(차지 중에도 궤도는 계속 좁아진다). 짧게 톡 누르면(약 0.1초 이하) 평범한 발사.
- 발사 속도 = 기본 × `1 + 돌격세기 × 차지` (세기: 파쇄 .5 · 질풍 .6 · 웜홀 .6 · 저거너트 .7 · 드레드 .9 · 템페스트 1.0 · 팬텀 1.1). 속도는 약 1.5초에 걸쳐 원래대로 돌아온다.
- 돌격 속도가 1.15배를 넘으면 **충돌 피해가 `1 + 0.6×(속도배율-1)` 배**로 늘고 히트스톱·흔들림이 커진다.
- 연출: 기체로 오므라드는 링과 빨려드는 입자, 차지 비례 떨림·발광·조준선 연장, 만땅 시 맥동 링 + 신호음, 발사 시 충격파·스파크·잔상.

### 강화 카드 풀 (4단 이후)
퍼센트포인트 단위로 오른다 — 추력 +5 · 충돌 +12 · 인력 +10 · 궤도 +12 · 산소 +12 · 점수 +10 · 비상 추진기 +1 (각자 상한 있음).

## 필드 확장과 지형 패턴
- **점점 넓어지는 시야**: 행성을 지날 때마다 필드 폭(`G.w`)이 420에서 최대 640까지 조금씩 넓어지고, 카메라는 그만큼 줌아웃한다. 행성·기체·속도·궤도 붕괴·별 자석은 `fs() = √(폭/420)` 배율로 같이 커져서 체감 속도와 난이도는 유지하고, 화면에는 더 넓은 지형이 보인다.
- **보스 아레나도 진행한 폭 그대로**: 보스가 시작되면 그 시점의 필드 폭으로 고정되고(보스전 동안 더 넓어지지 않는다), 줌아웃된 화면에 아레나 전체가 들어온다. 크기(보스·아레나 행성·공격 범위·블랙홀)는 `fs()`(√ 배율), 필드를 가로지르는 길이(광선 길이·세로 길이·행성 개수)는 `arenaK()`(선형 배율)를 따른다. 아레나 윗변·아랫변은 `G.arenaTop`/`G.arenaBot`. 갈림길 선택 중에도 폭은 고정된다.
- **지형 패턴**(`world.js`): 행성 몇 개마다 배치 방식이 바뀌고, 진행할수록 종류가 열린다.

| 패턴 | 열리는 때 | 모양 |
|---|---|---|
| 흩뿌림 | 처음부터 | 무작위 |
| 지그재그 | 행성 10개~ | 좌우 끝을 번갈아 오가는 긴 비행 |
| 기둥 | 14개~ | 중앙에 촘촘히 쌓인 짧은 비행 |
| 거대 가스행성 | 16개~ | 크고 포획 범위가 넓은 행성 하나 |
| 군집 | 18개~ | 3개가 붙어 연쇄 포획, 뒤에 긴 공백 |
| 떠다니는 행성 | 22개~ | 좌우로 천천히 흔들리는 행성 |

## 갈림길과 바이옴
보스를 쓰러뜨리면 몇 개 뒤에 **거대 암석 행성**이 나타난다. 이 행성의 궤도는 거의 줄지 않는다. 도착하면 **시야가 넓어지며(줌아웃)** 위쪽에 **왼쪽/오른쪽 항로**가 보인다. 각 항로는 행성 2개이고 라벨에 **바이옴 이름과 ▶ 다음 보스**가 적혀 있다. 항로의 첫 행성에 닿는 순간 길이 정해지고 반대편은 사라진다.

- **보스가 달라진다**: 한 판은 **8스테이지 = 보스 8종**을 만난다. 스테이지 2·3·5·7은 갈림길 항로가 두 보스 중 하나를 정하고(시리우스/베가, 아크투루스/폴라리스, 알데바란/안타레스, 베텔게우스/에타 카리나), 4스테이지는 괴물 행성 지대의 도전 보스(그롬) 고정, 나머지는 같은 보스에 **스타일만** 다르다. 좌우는 매번 섞인다. 보스는 총 12종.
- **행성 스타일(바이옴)**: 다음 보스까지 적용되고 보스전이 끝나면 일반으로 돌아온다.

| 바이옴 | 행성 | 점수 |
|---|---|---|
| 소행성대 | 작은 소행성, 포획 범위 좁음, 붕괴 빠름, **떠나면 부서짐** (보스전에서는 아레나 행성이 부서졌다 3턴 뒤 재생) | ×1.25 |
| 가스 성운 | 가스 거인 위주 — 포획 넓고 붕괴 느림 | ×0.8 |
| 적색 지대 | 적색왜성(약 45%)이 섞인 지대 — 일반·가스 행성도 나와 숨 돌릴 틈이 있다 | ×1.4 |
| 공허대 | 블랙홀이 2.2배 자주 나옴 | ×1.5 |
| 괴물 행성 | 일반 행성이 70%(가스·적색왜성 섞임). 행성 사이를 **괴물**이 떠다닌다(아래) | ×1.3 |

- **점진적 도입**: 첫 갈림길(프록시마 이후)은 가스 성운 vs 적색 지대처럼 이해하기 쉬운 것만, 두 번째 갈림길은 소행성대 vs 공허대, 그 뒤부터 4종에서 무작위.
- 바이옴은 **배경 전체의 색**으로 확실히 구분된다 (`draw-backdrop.js`, 색은 `BIOMES[...].look`). 소행성대=갈색 호박빛·굵은 먼지, 가스 성운=보라·자홍 구름, 적색 지대=핏빛·떠오르는 불씨, 공허대=거의 검정에 짙은 남색 비네트. 일반 행성의 색상 범위(`ph`)와 옆 벽 색도 바이옴을 따르고, 바이옴이 바뀌면 배경색이 부드럽게 넘어간다. 보스전 중에도 바이옴 배경이 유지된다.
- **괴물 행성 지대(도전 구역)**: 3번째 보스를 쓰러뜨리면 갈림길 없이 **반드시** 이 지대로 들어가(12행성) 도전 보스 **포식성 그롬**을 만난다. 그롬을 잡으면 평소처럼 갈림길이 나온다. 이후 갈림길에서도 한 항로로 나올 수 있다(직후엔 제외).
  - 괴물은 `G.mons` 에 따로 둔다(행성이 아니라 적). 포획되지 않고, 비행 중 부딪히면 보스처럼 튕겨 나가며(충돌 피해 = 보스와 같은 식) **맞을수록 작아지다 터진다**. 터지면 별이 쏟아지고 점수. 크기 ∝ 체력(기본 충돌 2~5번).
  - 종류 4가지: 점액(slime)·외눈(eye)·성게(urchin)·큰 입(maw). 크기·색(주로 녹색, 가끔 청록·연두)이 제각각이고, 좌우로 흔들리거나 제자리에서 돈다. 로직 `monsters.js`, 그림 `draw-monster.js`.
  - 보스 한 판이 시작되면 괴물은 모두 사라진다.
- 일정(일반 갈림길): 보스 격파 → 일반 행성 3개 → 갈림길 허브 → 항로 행성 2개 → (바이옴 행성들) → 격파 후 14번째 행성에서 다음 보스.
- **도착 처리는 한 곳**: 허브·항로 행성에 "자리 잡는" 모든 경로(포획, 비상 추진기 복귀)가 `player.js` 의 `forkArrive` 를 거친다. 허브면 시야 확대+배너, 항로 행성이면 항로 확정.

## 보스전 (대규모 업데이트)
10개 행성을 넘으면(보스를 잡은 뒤엔 14개) 항성 보스가 나타난다. 이때 현재 행성을 중심으로 **아레나**가 열리고 카메라가 고정된다.
행성은 4~6개이고, 모든 행성에서 보스까지 직선 경로가 다른 행성의 포획 범위에 막히지 않도록 배치를 검증한다.

### 규칙
- **산소 게이지가 크게 늘어난다** (24초 + 스테이지×6초 + 회차×2초, 산소 능력치가 절반만큼 반영). 날아다닐 때만 줄고, **궤도에 붙어도 회복되지 않는다.** 0이 되면 사망.
- **공격 수단은 충돌뿐.** 자유 비행 중 보스 몸통에 닿으면 피해(기본 26 × 충돌%, 연속 충돌 콤보 최대 +72%, 돌격 중이면 추가 배율 — 기체가 커질수록 판정도 조금 넓어진다). 맞으면 튕겨 나가 계속 날아간다.
- **보스는 우주선이 행성에 착지할 때마다 1턴.** 매 턴 공격하지 않고 **가끔(약 4턴에 1번)** 새 공격을 예고한다. 예고는 카운트다운 칩으로 알려 주고, **월드의 범위는 직전 턴(카운트 1)에만 강렬하게** 표시된다 (그 전엔 희미한 윤곽만). 0이 되는 턴에 발동한다. 오래 쉬었으면 확정 예고.
- **보스마다 공격력(`atk`, 산소 초)이 다르고 패턴마다 배율이 곱해진다.** 피해 = `atk × 패턴배율 × (1 + 0.15×회차)`. 맞으면 콤보 초기화, 넉백.
- **보스전 행성의 포획 범위는 좁다**: 아레나 행성의 포획 링 폭은 일반 40~48(가스 58), 서 있던 행성은 평소의 78%. 일부러 조준해야 잡히게 해서 보스를 향한 비행이 행성에 빨려 들어가는 일을 줄였다.
- **보스전 중에는 궤도가 붕괴하지 않는다.** 궤도 회전 속도도 58%로 느려져 조준할 시간이 충분하다.
- **맵이 계속 뒤로 밀려난다(스크롤)**: 보스는 화면 위에 붙어 있고, 아레나 창(`G.arenaTop`/`G.arenaBot`)이 위로 올라가면서 행성이 화면 아래로 흘러간다. 새 행성은 보스 바로 아래 등장선에서 계속 생기되(`boss-arena.js` 의 `feedPlanets`), **등장선에서 40 만큼 더 내려올 때까지는 유령 상태**(투명도 0.1, 포획·정면충돌·공격 표적 모두 안 됨)이고 그 아래에서 서서히 짙어지며 실체가 된다(`ACT`). 화면 아래로 지나간 행성은 사라진다. 그래서 한 행성에 오래 머물 수 없고 계속 위(앞)로 갈아타야 한다. 속도는 `SCROLL`(기본 12 px/초 × `arenaK()`)에 **이동 템포 배율**을 곱한 값이다: 첫 보스 1.0배에서 스테이지마다 일정하게 올라 후반 보스(7번째)에서 1.4배, **TON 618 은 예외로 1.8배**. 행성 간격은 거리 기준이라 템포가 빨라지면 시간당 행성 출현 빈도도 같은 비율로 늘어난다. 속도는 등장·격파 연출 중에는 멈춘다. 전투 시작 직후엔 몇 초에 걸쳐 서서히 빨라진다.
- **바닥은 낙사선**: 일반 지형과 같은 규칙(`die('심우주로 표류')`)으로, 비행 중에 화면 아래로 벗어나거나 행성과 함께 밀려 내려가면 죽는다(비상 추진기가 있으면 위쪽 행성으로 되돌아온다). 기체가 바닥에 가까워지면 아래쪽이 붉게 깜빡이고 `▼ 추락 위험 ▼` 이 뜬다(`draw-boss.js` 의 `drawFloorWarn`). 보스 등장·격파 연출 중에만 바닥이 튕겨 준다.
- 체력 50%(TON 618은 66%/33%)에서 **분노 페이즈** — 예고 슬롯이 하나 늘어난다.
- 보스 격파 직후에는 4초간 궤도 붕괴가 멈추고, 비행 중이던 산소 카운터도 초기화된다.
- 비상 추진기는 보스전에서도 유효 (부활 시 산소 최소 6초 보충).

### 공격 패턴 — 전부 **범위형**, 예고 → 도화선 → 폭발
착지한 순간 공격이 발동하지만 바로 맞지는 않는다. 범위가 붉게 차오르는 **도화선(약 1초)** 동안 범위 밖으로 빠져나가면 된다. 예고 단계에서도 "그 행성에 착지하면 위험하다"가 보이도록 행성 위에 자주 깔린다.

| 패턴 | 범위 | 비고 |
|---|---|---|
| 운석 낙하 | 원형 2~4개 | 위에서 운석이 떨어지며 폭발 |
| 혜성군 | 작은 원 5~7개 | 왼쪽부터 차례로 연쇄 폭발 |
| 부채꼴 광선 | 보스에서 뻗는 부채꼴 | 행성/플레이어 쪽을 겨냥 |
| 쌍제트 | 양쪽 대각선 부채꼴 2개 | TON 618. 가운데·바깥이 안전 |
| 플레어 폭발 | 보스 주변 큰 원 | 근처 행성에 앉지 말 것 |
| 흡수 블랙홀 | 인력 반경 150 + 중심 즉시 피해 | 4턴 유지, 비행 중 빨려 듦 |
| 행성 붕괴 | 행성 + 78 반경 | 폭발 후 행성 소멸 → 4턴 뒤 재생성. 앉아 있으면 튕겨 나간다 |
| 항성풍 | 화면 전체 | 4턴간 비행 중 옆으로 밀림 |

예고 지연 없이 발동 즉시 작동하는 지속형(블랙홀·항성풍)의 유지 턴은 `ATK[...].keep` 에서 정한다.

연출: 패턴 이름 컷인(스플래시), 보스 충전 오라와 빨려드는 입자, 상승 사운드, 수축 경고 링·십자선·깜빡임, 폭발 시 섬광·충격파 링·화면 흔들림·잔류 그을음.

### 보스전의 움직임과 열기
- **보스 이동**: 2스테이지(시리우스·베가…)부터 보스가 아레나 안을 좌우로 천천히 떠다닌다. 스테이지가 올라갈수록 폭과 속도가 늘고(최대 ±~125px, ≈80px/s), 위(HUD)로는 가지 않고 아래쪽으로만 조금 흔들린다. 프록시마(1스테이지)는 고정. 빔·제트·플레어처럼 **보스 위치에서 뻗는 공격이 나가는 동안은 멈춰 서고**, 예고 중인 빔은 움직이는 보스에서 목표를 계속 겨눈다.
- **열기(heat)**: 보스전 비행 중 **벽(좌우·천장)에 튕길 때마다** 기체에 **기체색 불꽃**이 한 단계 붙고(최대 5단계) 즉시 +14%씩 빨라진다. 불꽃은 단계에 따라 길고 많아지며, 충돌 피해도 단계당 +12%. 행성에 착지하거나 보스 공격에 맞으면 식는다. (`heat.js`)

## 타격감
히트스톱 · 슬로모션 · 줌 펀치 · 화면 플래시 · 화면 흔들림 · 확산 링/방향성 스파크 · 레이어드 합성음(타격 저음 + 노이즈 + 톤) · 진동(`navigator.vibrate`) · 행성 찌그러짐/맥동 · 별 수집 음정 체인 · 배너/토스트 연출 · 보스 사망 연출(연쇄 폭발 + 슬로모션).

## 배경음악
파일 없이 WebAudio로 실시간 생성한다. 평상시엔 느린 앰비언트(패드 + 아르페지오 + 베이스, 딜레이 공간감), 보스전엔 드럼(킥/하이햇/스네어)과 톱니파 베이스가 들어가는 빠른 곡으로 바뀌고 분노 페이즈·스테이지에 따라 템포와 조성이 올라간다. 사망·보스 격파 연출 중엔 음악이 끊긴다. 우하단 스피커 아이콘 또는 `M` 키로 음소거 (설정 저장).

## 테스트 훅
`window.__dbg` — `G`(공유 상태) · `get / jump(bossIndex) / sim(sec,{nobot,draw}) / set({hp,o2,shield,hops,stats}) / tier(n,path) / ship() / atk(kind,turns) / down() / up()`. 로직(`step`)과 렌더(`draw`)가 분리되어 있어 헤드리스로 보스전을 시뮬레이션할 수 있다. 봇은 보스전에서 서 있는 행성이 낮아지면 위쪽 행성으로 갈아탄다(`climbTarget`). (모듈 스코프라 전역 변수는 직접 접근할 수 없고 `__dbg.G` 를 쓴다.)

## 난이도 곡선
행성을 넘을수록 비행 속도↑, 붕괴 속도↑, 포획 범위↓, 행성 간격↑, 블랙홀 빈도↑.

## 조작
터치 / 클릭 / 스페이스. 강화 선택은 터치 또는 1·2·3.

## 구현
Canvas 2D + WebAudio, 외부 의존성 없음. `index.html` 은 껍데기이고 코드는 `js/` 의 ES 모듈이다. 최고 기록은 localStorage(`swingby_best`, `swingby_boss`, `swingby_mute`).

### 모듈 구조
상태는 `state.js` 의 **단일 객체 `G`** 에만 있고, 나머지 모듈은 `G` 를 읽고 쓰는 함수들이다. 화면 지표(`S, VW, VH, OX`)는 `V`.

| 파일 | 역할 |
|---|---|
| `main.js` | 초기화와 rAF 루프 (`step` → `draw`) |
| `state.js` | 캔버스, 화면 크기(`V`), 공유 상태 `G`, `newRun()` |
| `data.js` | 능력치 정의, 강화 카드, 보스(`BOSSES`), 공격(`ATK`), 스테이지(`STAGES`), 바이옴, 행성 종류별 붕괴 배율 |
| `ships.js` · `ship-art.js` | 기체 테크트리(증가량·돌격 세기) · 절차적 기체 그리기 |
| `stats.js` | 퍼센트 능력치 → 실제 수치 변환 (속도·인력·붕괴·산소·점수·충돌) |
| `camera.js` | 카메라 이동, 갈림길 줌, 보이는 범위(`viewTop/viewBot`) |
| `monsters.js` · `draw-monster.js` | 괴물 행성(적): 배치·이동·충돌·처치, 그리기 |
| `world.js` | 필드 폭 성장, 지형 패턴에 따른 행성·별·블랙홀·괴물 배치(`gen`) |
| `planets.js` · `scatter.js` · `fork.js` | 행성 생성·소행성 파쇄·애니메이션 · 별/블랙홀 배치 · 갈림길(허브·항로·확정) |

## 그래픽 v2 (롤백 가능)
기본은 새 렌더러(v2)이고, 주소 뒤에 **`?gfx=1`** 을 붙이면 예전 렌더러로 돌아간다(예전 코드는 지우지 않고 그대로 두었다. `?gfx=1` 화면은 이전 버전과 픽셀 단위로 같다). 전환 값은 `gfx.js` 의 `GFX.v`.
- **행성**(`draw-planet2.js`): 왼쪽 위에서 오는 빛의 음영과 어두운 면, 밝은 가장자리, 대기 테두리, 천천히 자전하는 대륙·구름, 가스행성의 줄무늬와 **고리의 앞뒤**, 적색왜성의 맥동하는 코로나, 소행성의 면과 분화구.
- **배경**(`draw-backdrop2.js`): 예전 배경 위에 깜빡이는 별 3겹(시차)과 십자 별, 필드 양옆 벽의 빛 번짐, 보스전 스크롤의 속도선.
- **타이틀**(`draw-title2.js`): 그라데이션 SWINGBY 로고, 훑고 지나가는 빛줄기, 글자를 감싸고 도는 궤도와 혜성.
- **효과**(`draw-fx2.js`): 가산 합성으로 빛이 번지는 꼬리·링·파티클, 별(수집품)의 번짐과 반짝임.

## 디버그판
- 주소 뒤에 `?debug` 를 붙이면 전용 기체 **디버그함**(`ships.js` 의 `dbg`, 트리 밖)으로 시작한다. 능력치는 상한 근처(충돌 400·산소 300·인력 300·추진기 9)이고 시작하자마자 **TON 618** 과 싸운다. `&boss=N` 으로 `BOSSES` 인덱스의 다른 보스도, `&zone=monster` 로 보스 없이 그 지역(바이옴)만 구경할 수도 있다.
- 기록(최고 점수·보스 격파)은 저장하지 않는다. 죽으면 같은 조건으로 다시 시작한다. 구현은 `debug-run.js`, 새 판 시작은 `progress.js` 의 `startRun()` 한 곳.

## 착지 규칙
- 행성에 붙을 때의 **최소 궤도 반지름**은 행성 반지름 + 20(필드 배율 적용). 한가운데로 파고들어도 이 바깥에서 돈다.
- 행성 한가운데(반지름의 40% 안)로 곧장 들어가면 정면충돌로 죽는다. 그 바깥은 전부 포획된다.
