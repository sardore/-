# 음악 스테이지 수록곡

이 폴더에 음악 파일을 넣고 `songs.json` 에 한 줄씩 적으면 곡 선택 화면에 자동으로 뜬다.

```json
[
  { "file": "my-song.mp3", "title": "곡 제목", "artist": "아티스트", "license": "CC0 (출처 URL)" }
]
```

- **저작권이 허락된 곡만** 넣는다 (직접 만든 곡, CC0·퍼블릭 도메인, 사용 허락을 받은 곡). 이 레포는 공개 링크로 배포된다.
- 30초 ~ 10분, mp3 · m4a · ogg · wav. 코스는 곡 길이와 곡의 세기(조용함/시끄러움)로 자동 생성된다.
- 플레이어는 게임 안의 "＋ 내 음악 파일 불러오기" 로 자기 기기의 곡도 쓸 수 있다(그 곡은 그 기기에만 저장되고 레포에는 올라가지 않는다).
