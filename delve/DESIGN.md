# 구덩이 DELVE — 기획서

**한 줄 요약**: Angband의 구조를 그대로 가져와 조작과 화면만 요즘식으로 바꾼 로그라이크.
마을에서 채비하고, 내려갈 때마다 새로 생기는 던전을 30층까지 파고들어 어둠의 군주를 쓰러뜨린다. 죽으면 끝.

세계관·이름·몬스터·아이템은 전부 새로 지었다(톨킨 고유명사 없음).

## Angband에서 가져온 것
| 요소 | 구현 |
|---|---|
| 마을 + 상점 | 잡화점, 무기점, 방어구점, 연금술점, 마법상, 암시장. 마을에 올 때마다 재입고 |
| 일회성 층 | 계단을 타면 층이 새로 생성된다. 탄 계단과 같은 종류의 계단 위에서 시작(연속 계단) |
| 층의 느낌 | 도착하면 위험도, 어느 정도 돌아다니면 보물 수준을 문장으로 알려준다 |
| 속도/에너지 | 속도 +10 = 턴 2배. 모든 개체가 에너지 100이 되면 행동 |
| 잠과 은밀 | 몬스터는 대부분 자고 있고, 가까이서 시끄러울수록 빨리 깬다 |
| 미감정 | 물약·두루마리·마법봉·막대·반지·부적은 게임마다 겉모습이 섞이고 써 봐야 안다 |
| 귀환 / 깊은 하강 | 귀환은 마을↔최대 도달층, 깊은 하강은 3층 아래 |
| 에고·아티팩트 | 접두 에고 29종(화염의, 학살의, 수호의, 속도의…), 고정 아티팩트 10종 |
| 유니크·퀘스트 | 유니크 9종. 20층 부관을 잡아야 아래 계단이 열리고, 30층 군주를 잡으면 승리 |
| 떼·증식·숨결 | 사냥개 무리, 증식하는 벌레, 현재 체력 비례 숨결(저항 없으면 치명적) |
| 금고(vault) | 영구벽 방에 층 수준보다 강한 괴물과 좋은 보물 |
| 원소 저항 | 화염·냉기·독. 장비 저항과 일시 저항은 중첩 |
| 허기, 함정, 굴착 | 식량, 함정문·순간이동·독침·소환·화염 함정, 돌무더기 |

## 요즘식으로 바꾼 것
- **터치 우선**: 옆 칸 탭 = 이동/공격, 먼 칸 탭 = 그곳까지 이동, 밀기 = 한 걸음. 키보드(방향키·숫자패드·vi키)도 전부 지원.
- **자동 탐험**: 안 가본 곳과 보이는 물건을 알아서 찾아가고, 괴물이 보이면 멈춘다. 다 돌면 계단으로.
- **자동 줍기, 자동 대상 지정**: 사격·주문은 지정한 대상(없으면 가장 가까운 적)에게.
- **빠른 사용 칸**: 치료 물약, 순간이동, 귀환이 항상 손 닿는 곳에.
- **숫자를 보여준다**: 피해량, 몬스터 체력·능력·주문 목록을 탭 한 번으로.
- **장비는 주운 즉시 감정**(룬 감정 방식), 광원은 연료 없음.
- **층을 줄였다**: 100층 → 30층, 지도 198×66 → 72×40. 한 판이 짧아지도록.
- 미니맵, 자동 저장(죽으면 저장 삭제), 명예의 전당.

## 구조
`js/data.js` 정의 / `js/map.js` 생성·시야·경로 / `js/game.js` 규칙 전체(DOM 없음) / `js/ui.js` 화면·입력·저장

## 검증 (`npm test`)
- 1~30층 생성 360회: 통행 가능한 칸이 전부 이어져 있음(금고 포함).
- 아이템 2만여 개 생성·이름·설명에 깨진 값 없음, 전 몬스터 설명 정상.
- 직업×종족 봇 플레이, 20~30층 강화 캐릭터 플레이: 상태 불변식 유지.
- 저장→불러오기 후 같은 입력에 같은 결과. 상점 금화 계산.

## 알려진 한계 / 다음 단계
- 밸런스는 봇으로 초반만 맞췄다. 10층 이후 난이도 곡선과 최종 보스는 사람이 깨 본 적이 없다.
- 빠진 것: 집(보관함), 저주, 스턴·출혈, 능력치 감소/복구, 사제·도적 등 직업, 몬스터 기억(lore), 구덩이·둥지 방.
