# 구덩이 DELVE — 기획서

**한 줄 요약**: Angband의 구조를 가져와 화면·조작·성장을 요즘식으로 다시 만든 픽셀아트 로그라이크.
마을에서 채비하고, 내려갈 때마다 새로 생기는 던전을 40층까지 파고들어 어둠의 군주를 쓰러뜨린다. 죽으면 끝.

세계관·이름·몬스터·아이템·그림은 전부 새로 만들었다(톨킨 고유명사, 외부 에셋 없음).

## Angband에서 가져온 것
| 요소 | 구현 |
|---|---|
| 마을 + 상점 | 잡화점, 무기점, 방어구점, 연금술점, 마법상, 암시장. 마을에 올 때마다 재입고 |
| 일회성 층 | 계단을 타면 층이 새로 생성된다. 탄 계단과 같은 종류의 계단 위에서 시작 |
| 층의 느낌 | 도착하면 위험도, 어느 정도 돌아다니면 보물 수준을 문장으로 알려준다 |
| 속도/에너지 | 속도 +10 = 턴 2배 |
| 잠과 은밀 | 몬스터는 대부분 자고 있고, 가까이서 시끄러울수록 빨리 깬다 |
| 미감정 | 물약·두루마리·마법봉·막대·반지·부적은 판마다 겉모습이 섞인다 |
| 귀환 / 깊은 하강 | 귀환은 마을↔최대 도달층, 깊은 하강은 3층 아래 |
| 에고·아티팩트 | 접두 에고 29종, 고정 아티팩트 14종 |
| 유니크·퀘스트 | 유니크 12종. 20층 부관을 잡아야 아래가 열리고, 40층 군주를 잡으면 승리 |
| 떼·증식·숨결·금고 | 사냥개 무리, 증식하는 벌레, 체력 비례 숨결, 영구벽 금고 |

## 이번에 키운 것
### 그래픽 (`js/gfx.js`, `js/ui.js`)
- 글자 타일 → **12×12 픽셀아트**. 몬스터 계열 25종 + 직업 5종 + 아이템 20종 스프라이트를 코드 안에 문자열로 정의하고, 색만 바꿔 112종 몬스터를 그린다.
- **지형대별 타일셋**(바닥·벽 윗면·벽 앞면·문·계단·물·용암·샘·제단)을 절차적으로 생성. 벽은 아래가 뚫려 있으면 앞면이 보이는 2.5D.
- **조명**: 횃불 반경에 따라 밝기가 떨어지고 일렁인다. 기억만 하는 곳은 어둡게, 용암은 주변을 물들인다.
- **움직임**: 이동 보간, 공격 돌진, 피격 섬광, 사망 파편, 날아가는 발사체와 폭발, 피해 숫자, 화면 흔들림, 레벨업 연출, 체력 낮을 때 붉은 테두리, 지형대별 먼지·눈·불씨.
- **소리**: 걸음·타격·주문·줍기·문·계단·레벨업 등 합성 효과음(더보기에서 끌 수 있음).

### 규모
- 30층 → **40층**, 지도 72×40 → 84×46. **지형대 5개**(8층씩): 옛 광산 → 지하묘지 → 얼음 동굴 → 용암 굴 → 심연. 지형대마다 색, 물/용암, 잘 나오는 몬스터가 다르다.
- **동굴형 층**(세포 자동자)과 방형 층이 섞여 나온다.
- 몬스터 65 → **112종**(새 계열: 뱀, 해골, 새, 고양잇과, 지네, 설인, 바위 포식자 등), 깊은 층 전용 14종.

### 게임성
- **직업 5개**(전사·마법사·레인저·**사제·도적**), 전 직업에 **기술**: 전사 강타/돌진/회전베기…, 레인저 조준 사격/연사/화살비…, 도적 급소 찌르기/소매치기/그림자 걸음…, 사제 응징/치유/심판의 구…, 마법사는 마법서 주문. 총 43개.
- **특성**: 5레벨마다 3개 중 1개 선택(24종, 일부 중첩). 판마다 빌드가 달라진다.
- **암습**: 잠든 적은 반드시 맞고 치명타. 도적은 3배.
- **던전 요소**: 보물상자(가끔 함정), 샘(마시면 무작위 효과), 제단(한 번 기도), 용암, 한 종류의 괴물이 가득한 **소굴**.
- **마을**: 물건을 맡기는 **집**, 유니크를 잡으면 돈을 주는 **모험가 길드**.
- 몬스터 처치 기록, 신성 속성, 새 아이템·아티팩트.

## 검증 (`npm test`)
- 1~40층 생성 480회(동굴·용암 포함): 통행 가능한 칸이 전부 이어져 있음.
- 아이템 2만 6천여 개 생성·이름·설명 정상, 전 몬스터 설명 정상.
- 직업 5 × 종족 4 봇 플레이, 12~40층 강화 캐릭터로 전 기술 사용: 상태 불변식 유지.
- 저장→불러오기 후 같은 입력에 같은 결과. 상점·특성·샘·제단·상자·집·현상금 동작.

## 알려진 한계 / 다음 단계
- 밸런스는 봇으로 초반만 맞췄다. 10층 이후와 보스는 사람이 깨 본 적이 없다.

- 빠진 것: 저주, 스턴·출혈, 능력치 감소, 펫, 퀘스트 층, 음악.
