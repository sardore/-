# 메가리그 MEGA LEAGUE — 2 vs 2

기존 4인 배틀(메가리그)의 **캐릭터 스펙(HP·실드·방어·에너지·속도·특성·기술 코스트/효과)만 가져와서** 엔진·그래픽·화면을 전부 새로 짠 버전.

## 규칙 요약
- 덱 4장 = 필드 2 + 후열 2. 행동 순서는 [내 1번 → 상대 1번 → 내 2번 → 상대 2번].
- 한 번의 행동 = 에너지 모으기 / 기술 사용 / 교체 (팀당 3회). 에너지는 캐릭터마다 따로 가진다(R·W·B, 최대 4~6).
- 피해: 기본 위력 × 66~100% − 방어 → 실드 → HP 보호막 → HP. 치명타 ×1.5(방어 무시).
- 상태이상 8종(독·감속·마비·화상·냉동·특성/기술/회복 봉인), 그랜드필드, 예약 공격(슈가스웜프·파이어스톰·활공 등), 무적/방벽, 반사·회피·피해경감 등 특성.
- 필드 캐릭터가 쓰러지면 그 슬롯 차례에 후열이 출전. 상대 4명을 모두 쓰러뜨리면 승리.

## 구조
| 파일 | 역할 |
|---|---|

| `js/main.js`, `css/style.css` | 모바일 우선 UI, 덱 구성, 결제/선택 팝업, 이펙트 |
| `test/engine.test.mjs` | `node --test test/engine.test.mjs` |

## 캐릭터 (54장)
원본 스펙의 54장 전부 구현. 수치(HP/실드/방어/최대E/속도)와 기술 코스트·위력은 스펙 그대로이고, 아래 항목만 새 엔진에 맞게 **간략화**했다.

| 카드 | 간략화 |
|---|---|
| 플래피스 | 에너지 직조(피격 W1 / 아군 피격 W½ / 기술 후 R1)를 매번 선택하지 않고, 빈 칸이 있으면 자동 획득 |
| 빙마기수 | 기수·야수 두 저장소 → 하나의 저장소(최대 6)로 합침. 날뛰기는 낸 에너지 총량×10D |
| 서킷 | 볼티지버스트는 연속 행동 준비 없이 즉시 발동 (W 수²×15D, B 획득) |
| 타임오러 | 운명의 시계는 아군 기술(시침)·본인 기술(분침)에만 반응. 시간 가속은 "재추첨" 없이 항상 +½. 타임리콜은 대상의 턴 시작 기록(HP·상태)을 사용 |
| 정글즈 | 소환수는 별도 유닛이 아니라 정글즈에 붙은 동료: 정글즈가 맞을 피해를 먼저 대신 받고, 정글즈의 차례가 끝날 때 한 번씩 행동한다 (최대 2마리, 정글즈가 물러나면 사라짐) |
| 아비게이트 | 심해의소용돌이는 한 번에 한 칸씩만 교환 |
| 실브래 | 드래곤메모리는 `plus` 가 있는 기술은 복사하지 않음 (현재 로스터에는 해당 없음) |
| 이그드라실 | 생명의 문턱은 아군 진영에만 적용 |
| 공통 | 같은 형태 계열(화락나리/루나리/호리진탈) 중복 금지, 온라인 대전은 포함하지 않음 |
